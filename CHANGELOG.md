# Changelog

## 0.1.0 — 2026-11-21
First public release.
- Method: 14 chapters (scoping, recon, test design, black-box, white-box, evidence, severity and priority,
  bug reports, verification, reporting, regression, safety in production, QA with AI agents) and 10 checklists.
- CLI `oqa`: `doctor`, `init`, `login`, `recon`, `scan` (Chromium, Firefox or WebKit), `lint`, `report`, `export` (CSV, GitHub issues), `new-finding`.
- Demo app with planted bugs, an answer key, and a complete example engagement with its PDF report.
- Claude Code plugin: 8 commands, 4 agents, 1 skill.

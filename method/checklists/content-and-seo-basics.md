# Checklist · Content and SEO basics

Not an SEO audit. These are the content defects users and search engines both notice.

- [ ] No placeholder or leaked text: `Lorem ipsum`, `TODO`, `undefined`, `null`, `NaN`, `[object Object]`, raw enum names (`STATUS_PENDING`), template tags (`{{name}}`)
- [ ] Spelling and grammar on headings, buttons and emails
- [ ] Numbers, dates and currencies formatted for the audience's locale
- [ ] Every page has a unique, descriptive `<title>` and meta description
- [ ] One `h1` per page that says what the page is
- [ ] Links: no 404s (`oqa scan`), no links to staging/localhost, external links open where expected
- [ ] Custom 404 page that helps the user get back
- [ ] Social preview: `og:title`, `og:description`, `og:image` present and correct when the URL is shared
- [ ] Legal pages present and reachable (privacy, terms, cookies, refund) as the business requires
- [ ] Contact details and support links work (`mailto:`, `tel:`, the form actually sends, to the owner's test address)
- [ ] Favicon and app icons present
- [ ] Claims on the page (prices, "used by N companies", feature lists) match what the app actually does. Mismatches are findings

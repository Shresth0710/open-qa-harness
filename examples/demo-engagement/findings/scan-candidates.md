### QA-SCAN-01 — Password form on /login is sent with GET, so the password goes into the URL
- **Severity:** High
- **Priority:** P3
- **Status:** Unconfirmed
- **Category:** Security
- **Where:** http://localhost:4173/login · desktop 1440 · Chromium
- **What the user experiences:** The password a person types ends up in the address bar, the browser history and the server's logs.
- **Steps to reproduce:**
  1. Open http://localhost:4173/login.
  2. Fill in the form that has a password field and submit it.
  3. Look at the address bar after submitting.
- **Expected:** Forms with a password field use method="post"; the password never appears in a URL.
